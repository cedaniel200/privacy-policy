# privacy-policy

Política de privacidad de las aplicaciones móviles publicadas por el responsable del proyecto.

Página única, bilingüe (español / inglés) y válida para Google Play, Apple App Store y
Huawei AppGallery.

## Publicación

GitHub Pages sirve `index.html` desde la raíz de `main`:

- URL: <https://cedaniel200.github.io/privacy-policy/>
- Play Console: pegar esa URL en la ficha de cada app (*Contenido de la aplicación →
  Política de privacidad*).

## Mantenimiento

- **App nueva**: añadir su nombre en la sección 1 (ES y EN).
- **SDK nuevo con datos** (analítica, informes de fallos): actualizar la sección 3, la fecha
  de «Última actualización» y el formulario de Seguridad de datos de cada app.
- **Cambio de correo**: metadatos, sección 8 y sección 11, en ambos idiomas.
- **Coherencia obligatoria**: la política y el formulario de Seguridad de datos de Play
  declaran lo mismo. Una discrepancia entre ambos es motivo de retirada.
- **`app-ads.txt`** (AdMob): debe servirse desde la raíz del dominio, así que no funciona
  desde este repositorio de proyecto. Haría falta un dominio propio.
