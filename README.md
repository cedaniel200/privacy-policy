# privacy-policy

Política de privacidad de las aplicaciones móviles publicadas por Cesar Daniel Meneses Guevara.

Una sola página, bilingüe (español / inglés), válida para Google Play, Apple App Store
y Huawei AppGallery.

## Publicación

GitHub Pages sirve `index.html` desde la raíz de `main`:

- URL: <https://cedaniel200.github.io/privacy-policy/>
- Play Console: pegar esa URL en la ficha de cada app (*Contenido de la aplicación → Política de privacidad*).

## Mantenimiento

- Añadir una app nueva: agregar su nombre y su id de paquete en la sección 1 (ES y EN).
- Nuevo SDK con datos (analítica, informes de fallos): actualizar la sección 3, la fecha
  de «Última actualización» y el formulario de Seguridad de datos de cada app.
- Cambiar el correo de contacto: sustituirlo en las secciones 1, 8 y 11 de ambos idiomas.

La coherencia entre esta política y el formulario de Seguridad de datos de Play es
obligatoria: una discrepancia entre ambos es motivo de retirada.
